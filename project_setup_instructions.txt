2. ИНСТРУКЦИЯ ПО УСТАНОВКЕ:

# 1. Создание виртуального окружения
python -m venv venv

# 2. Активация виртуального окружения
# Для Windows:
venv\Scripts\activate
# Для Linux/Mac:
source venv/bin/activate

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Создание базы данных
python manage.py migrate

# 5. Создание суперпользователя
python manage.py createsuperuser

# 6. Сборка статических файлов
python manage.py collectstatic

4. ВАЖНЫЕ НАСТРОЙКИ В settings.py:

# Основные настройки
DEBUG = True
ALLOWED_HOSTS = ['*']  # Измените для продакшена
SECRET_KEY = 'ваш-секретный-ключ'

# Настройки статических файлов
STATIC_URL = 'static/'
STATICFILES_DIRS = [os.path.join(BASE_DIR, 'static')]
STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles')

# Настройки медиа файлов
MEDIA_URL = '/media/'
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')

# Настройки локализации
LANGUAGE_CODE = 'ru'
TIME_ZONE = 'Asia/Bishkek'
USE_I18N = True
USE_L10N = True
USE_TZ = True

# Настройки CKEditor
CKEDITOR_UPLOAD_PATH = "uploads/"
CKEDITOR_5_CONFIGS = {
    'default': {
        'toolbar': ['heading', '|', 'bold', 'italic', 'link', 'bulletedList', 'numberedList', 'blockQuote'],
        'height': '300px',
        'width': '100%',
    },
}

5. ПРОВЕРКА РАБОТОСПОСОБНОСТИ:
# Запуск сервера разработки
python manage.py runserver 127.0.0.1:8000

6. ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ ДЛЯ ПРОДАКШЕНА:
- Установить DEBUG = False
- Настроить ALLOWED_HOSTS
- Настроить безопасные настройки SSL
- Настроить правильный сервер (например, Nginx + Gunicorn)

7. ВАЖНЫЕ МОМЕНТЫ:
- Проверить все пути к файлам в проекте
- Убедиться, что все миграции применены
- Проверить права доступа к папкам media и static
- Настроить правильные URL-паттерны в urls.py
- Проверить работу мультиязычности
- Проверить работу CKEditor
- Проверить работу загрузки файлов

8. ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ:
- Если не работают статические файлы: выполнить python manage.py collectstatic
- Если не работают медиа файлы: проверить настройки MEDIA_URL и MEDIA_ROOT
- Если не работает CKEditor: проверить настройки в settings.py и установленные пакеты
- Если не работает мультиязычность: проверить настройки LANGUAGE_CODE и LANGUAGES

9. РЕКОМЕНДАЦИИ ПО БЕЗОПАСНОСТИ:
- Изменить SECRET_KEY
- Настроить правильные ALLOWED_HOSTS
- Включить SSL в продакшене
- Настроить безопасные настройки сессий и куки
- Регулярно обновлять зависимости
